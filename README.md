# Supply Chain Data Engineering & AI Roadmap

This repository contains end-to-end projects focused on solving real-world supply chain problems using data engineering and machine learning.

## Projects

### 1. Fulfillment Risk Prediction System
Predicts and ranks e-commerce orders based on risk of late delivery.

- Feature engineering using logistics and geospatial data
- Handles class imbalance
- Provides risk scoring for operational prioritization

- Develop production-style data pipelines
- Apply machine learning to real operational problems
- Create deployable systems (API / dashboard)
